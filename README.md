# Nothing Toolbox (starter project)

Android Studio project scaffold in Kotlin + Jetpack Compose, inspired by the Kaorios Toolbox APK's visible structure and workflow.

## Current status
This is a UI/architecture starter, not a feature-complete clone. The supplied APK is compiled bytecode, not original source. Root operations and system patch actions are intentionally not implemented yet.

## Build
Open this folder in Android Studio (recent stable version), sync Gradle, then run on an Android device/emulator.

## Planned modules
- Dashboard and device/root status
- Patch workspace (DEX/JAR import, editing session, export)
- Module/script manager
- Device properties tools
- Game/performance tools
- Settings and operation logs

Do not include or redistribute private keybox/attestation material.
